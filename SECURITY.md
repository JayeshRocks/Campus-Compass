# Security Policy

## Supported Versions

Currently, only the `main` branch (latest version) is supported with security updates.

## Reporting a Vulnerability

If you discover a security vulnerability within Campus Compass, please send an e-mail to the core maintainers or open a private security advisory on GitHub. 

Please do **not** disclose the vulnerability publicly until it has been verified and patched.

We will endeavor to respond to all reports within 48 hours and patch verified vulnerabilities as soon as possible.
