# Contributing to Campus Compass

First off, thank you for considering contributing to Campus Compass! It's people like you that make Campus Compass such a great tool for the MIT Bengaluru community.

## Development Setup

1. Fork the repository.
2. Clone your fork: `git clone https://github.com/your-username/Campus-Compass.git`
3. Install dependencies: `npm install`
4. Create a `.env.local` file using `.env.example` as a template.
5. Start the development server: `npm run dev`

## Pull Request Process

1. Ensure your code follows the existing Tailwind architecture and passes all TypeScript checks.
2. Update the README.md with details of changes to the interface, if applicable.
3. Open a Pull Request against the `main` branch.
4. The core team will review your PR and merge it once approved.
